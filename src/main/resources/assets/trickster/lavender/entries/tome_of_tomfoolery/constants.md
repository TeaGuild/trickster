Described here are [Scribing Patterns](^trickster:editing) which set the glyph of the circle they're drawn in to a literal value.

;;;;;

<|revision@trickster:templates|pattern=1\,4\,7,title=Foundational Revision|>

Replaces the glyph with the number two. All other numbers can be created using [Arithmetic](^trickster:distortions/arithmetic).

;;;;;

<|revision@trickster:templates|pattern=6\,3\,0\,2\,5\,8,title=Catalogue Revision|>

Replaces the glyph with an empty [list](^trickster:distortions/list).

;;;;;

<|revision@trickster:templates|pattern=2\,5\,8\,6\,3\,0,title=Atlas Revision|>

Replaces the glyph with an empty [map](^trickster:distortions/map).
